## ✨ 核心特性

### 🔮 1. 自由异形悬浮镜头 (Free-Shape Facecam)
- **5 种几何美学形状**：在**圆形**、**苹果超椭圆 (28% Squircle)**、**微圆角矩形**、**赛博六边形**与**横向胶囊椭圆**之间任意切换。
- **全局自由拖拽**：带有安全边缘限制，可将镜头气泡放置在屏幕任意角落。
- **滚轮顺滑缩放**：鼠标悬停在气泡上，滑动滚轮即可在 100px 到 360px 之间连续缩放。
- **苹果连续互通相机支持**：无缝支持 MacBook 自带镜头、外接 USB 摄像头，以及将 iPhone 作为超清无线网络摄像头。
- **硬件环境自适应感知**：自动处理 MacBook 合盖断电休眠、QuickTime 独占锁等硬件状态。
- **水平镜像翻转**：一键开启/关闭镜头镜像 (`🪞`)。
- **多色发光边框**：霓虹蓝、赛博紫、翡翠绿与极简无边框。

### 🔴 2. 丝滑屏幕与音频录制 (Frictionless Screen Recording)
- **杜绝无限权限死循环**：完备的底层状态机设计，取消屏幕选择时优雅处理，不反复弹窗骚扰。
- **三种录制模式**：
  1. 🖥️ + 📷 **屏幕 + 镜头气泡**：演讲 PPT、代码走查、教程制作的最佳拍档。
  2. 📹 **纯镜头出镜模式**：不共享屏幕，专注录制个人陈述、视频备忘录。
  3. 💻 **纯屏幕录制模式**：专注捕获软件窗口或标签页，搭配麦克风画外音。
- **3 秒视觉倒计时**：3... 2... 1... 启动录制，留出切换窗口与调整呼吸的从容时间（支持一键跳过）。
- **实时麦克风跳动电平表**：基于 Web Audio API 的实时音频分析器，说话时绿色 LED 条实时跳动，彻底杜绝“录了半小时才发现没开麦”的尴尬。
- **60 FPS 硬件合成引擎**：基于 GPU 加速的 `<canvas>` 管道，将屏幕与异形镜头精准裁切并合成为高帧率视频流。
- **即时预览与导出**：录完即看，一键下载为高清 **MP4 / WebM** 文件。

### 🎬 3. 沉浸演示模式 (`Key: H`)
- 录制时按下键盘 **`H`** 键，瞬时隐藏所有顶部栏和底部控制 Dock，只留下纯净的内容展示和人像镜头。再次按 `H` 即可唤出。

## 🚀 快速开始

PipCast **无任何构建步骤、无 node_modules、无外部依赖**。

### 方式 1：macOS 双击即用（强烈推荐）
直接双击项目根目录下的 **`start.command`**。
- 会以微秒级启动一个零开销本地服务 `http://localhost:8000` 并在 Chrome 中打开。
- Chrome 对 `localhost` 赋予 100% 完整的系统硬件权限与持久化支持。

### 方式 2：跨平台命令行
```bash
# macOS 或 Linux
./scripts/start.sh

# Windows
.\scripts\start.bat

# 或者直接用 Python / Node 自带服务
python3 -m http.server 8000
# 或: npx serve .
```

### 方式 3：直接浏览器打开
直接在浏览器中双击 **`index.html`** 打开即可。

## 🔒 隐私与本地优先承诺

PipCast 遵循 **100% Local-First (本地优先)** 原则：
- **0 字节云端上传**：所有图像裁切、60 FPS 画面合成与音频混音均在浏览器原生进程中完成。
- **无追踪、无打点**：不包含任何第三方追踪代码、Cookie 或远程依赖。
- **支持完全断网运行**：即使拔掉网线，PipCast 也能完美运行并导出视频。
